## ✨ Features

* 📊 DSA Dashboard with progress analytics.
* 📚 Problem tracker with LeetCode integration.
* 🔁 Smart Revision Queue with due dates.
* 📝 Rich Notes Editor.
* ❤️ Favorites & Achievements.
* 👥 Community Chat & Study Rooms.
* 🏆 Leaderboard & Streak Tracking.
* 🔐 Authentication with Email & Username.
* 👨‍💼 Admin Workspace for moderation and announcements.
